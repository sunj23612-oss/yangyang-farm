# 洋洋农场 · 联网版

星露谷式可交互农场小游戏，支持账号系统、一号一档、好友互访与偷菜、角色与宠物自定义、屋内生活、昼夜季节循环。纯 Python 标准库后端 + 单文件 HTML 前端，**零第三方依赖**。

## 功能一览

- **账号系统**：注册 / 登录 / 会话 token（pbkdf2_hmac-sha256 12 万轮 + secrets token），一号一档，云端存档自动同步（每 20 秒 + 关键操作即时）
- **昼夜交替与季节系统**：一天 240 秒（游戏时间放缓），有昼夜明暗、星空月亮；春夏秋冬四季循环，季节改变色调与落叶特效；夜晚宠物睡觉、人物可选择睡觉或继续工作（继续工作有小概率抱怨台词）
- **可交互土地**：星露谷式瓦片地块（非背景图），人物须走到地块旁才能锄地 / 播种 / 浇水 / 收获；闲置 3 天未耕种的地块退回荒地
- **田地花园无缝格网**：田地 24 格、花园 12 格全铺满、格子间无缝隙，鱼塘水面直接划分在地面上（同好友农场视图）
- **人物受控移动**：点击地面 / 方向键 / WASD 移动，走位触发走路动画；农事、进出门、钓鱼均须走到目标附近再交互
- **角色自定义（1–2 人）**：数量 1–2 人、性别单选（形象与性别绑定：男=徐明涛 / 女=孙靖宇，无额外选项）、自定义姓名；可同步改名换肤
- **宠物自定义（0–2 只）**：猫 / 狗可选，5 款免费模型（哈士奇 / 橘猫 / 德牧 / 灰猫 / 牧羊犬），默认名「猫一」「猫二」，可改名；宠物自主漫游、有台词气泡（按品种 / 名称适配 5 模型 × 白天 / 夜晚 / 守夜 / 投喂 / 偷吃 / 踩踏词表）
- **台词系统**：人物说话按对象区分（对他人 / 对宠物 / 自言自语），说话与动作系统解绑——台词不打断移动、不强制切动画
- **好感度（0–100）**：提升条件仅为投喂（喂鱼 +3/次，进度缓慢）；好感越高宠物偷吃菜 / 踩坏田地的几率越低（100 好感约降至 15%）；猫会搞破坏，**狗不会**
- **宠物守卫**：仅狗能守夜（猫不可选），守夜每夜略降 2 好感；夜晚狗不睡觉、看守菜园花园，好感奖惩平衡
- **背包与装备**：锄头 / 种子 / 水壶收进背包，装备到手上使用；未装备时点击即为移动
- **屋内页面（厨房+卧室）**：家具齐全（床=睡觉 / 灶台=烹饪 / 餐桌等，点击互动）；进房须走到小屋门口，出房须走到大门并点击交互；屋内移动已提速
- **告示牌**：菜园 / 花园 / 鱼塘改为插地告示牌（素材实拍，白字黑描边 22px 主场景 / 18px 好友页，清晰醒目）
- **好友系统**：添加好友、好友列表、好友农场只读视图
- **偷菜（进入对方农场）**：点好友「去偷菜」→ 我方人物进入对方农场页面 → 走到成熟作物格子旁自动摘下入包；每好友每日限偷 **3 次**，超限提示并拒绝
- **钓鱼**：不设额外按钮——点击鱼塘 / 告示牌，人物走到岸边自动打开钓鱼面板（游标粗细控制在鱼带内收竿）
- **厨房 / 商店 / 背包**等玩法保留
- 页面全屏自适应（桌面与手机视口均可）；顶部为 保存 / 同步 / 好友 / 自定义 / 退出 功能键，底部为工具栏与背包；底部固定素材署名

## 快速开始

```bash
# 需要 Python 3（任意 3.8+ 即可，无需安装任何第三方包）
# 注意：必须带端口参数启动（默认 8000，本项目实际使用 8123）
python -u server.py 8123
```

浏览器访问：<http://127.0.0.1:8123/>

## 部署到公网

**当前公网隧道地址（localtunnel，临时）：<https://grumpy-dancers-nail.loca.lt/>**

- 任意有 Python 3 的服务器 / 云主机 / NAS 均可直接运行本服务
- 前端由后端同源静态托管（`web/洋洋农场.html`），**无跨域问题，无需单独部署前端**
- 如需 HTTPS / 域名，用 nginx / caddy 反向代理到本服务端口即可
- 数据文件 `farm.db`（SQLite）自动创建于 server.py 同目录，备份该文件即可备份全部账号；停机时建议执行 `sqlite3 farm.db "PRAGMA wal_checkpoint(TRUNCATE);"` 合并 WAL

### 本地隧道（localtunnel）说明

- 当前公网地址即为本地隧道的临时转发入口，需要本机已启动 `python -u server.py 8123` 且隧道进程存活；**隧道进程停止即失效**，需重新建立
- 重启隧道**必须带 `--subdomain` 参数保持地址不变**：`npx localtunnel --port 8123 --subdomain grumpy-dancers-nail`
- 真人浏览器访问时，隧道确认页会要求输入本机公网 IP（`1.181.190.19`，每公网 IP 7 天输入一次）后点 Continue
- 程序化访问（脚本 / curl）需在请求头加 `bypass-tunnel-reminder: 1` 跳过确认页
- **临时隧道不保证搜索引擎收录**：此地址为本地转发，域名随机、进程停即失效，无法作为稳定 SEO 落地页；「洋洋农场」关键词的长期关联落地在当前为页面 SEO 元信息（title / description / keywords）。如需可被搜索的长期公网托管，请将本服务部署到自有服务器或 PaaS（如 Render / Fly / Vercel 等，本项目为 Python + SQLite 后端，需支持运行 Python 服务的平台）
